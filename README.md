# 两个人看的日记 · 演讲练习网站

这是可直接用于 GitHub Pages 的静态网页，无需安装依赖或构建。

## 上传文件

将本文件夹内的 `index.html`、`reading.js`、`.nojekyll` 和本说明上传到仓库根目录。网页样式已包含在 `index.html` 中，无需另传 CSS、截图、PDF 或旧版 app.js。

## 另外上传音频

本交付文件夹不含音频。请把项目中的两个完整音频文件夹上传到同一仓库根目录，保留文件夹及文件名称：

```text
仓库根目录/
├── index.html
├── reading.js
├── .nojekyll
├── README.md
├── 逐句朗读音频/
│   ├── 大家好.m4a
│   ├── 川原小捺.m4a
│   ├── 中村璃音.m4a
│   └── ……其余逐句音频，保持现有名称
└── 全文朗读音频/
    └── 全文.m4a
```

音频目录须与 `index.html` 同级。网页已使用相对路径，支持 GitHub Pages 的仓库子路径地址。没有上传音频时，页面可以浏览，但无法播放。

## 发布与检查

使用 GitHub Pages 发布仓库根目录即可。发布后检查全文播放、中文短句播放、姓名选择与姓名发音。手机通过发布后的 HTTPS 网站地址访问，不使用电脑上的 127.0.0.1 预览地址。

当前功能包括中日文对照、拼音、单页滚动、逐句示范、全文朗读和学生姓名选择。学生录音和发音评测尚未接入。
