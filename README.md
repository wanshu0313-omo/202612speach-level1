# 中文演讲练习 · 初级 / 中级

左上角选择文章：初级《两个人看的日记》或中级《你，不敢吗？》。两篇均不包含姓名选择，保留逐字拼音和中日文对照。初级已接入逐句与全文音频，中级已接入部分短句音频，其余后续接入。

上传 index.html、reading.js、.nojekyll 到 GitHub 仓库根目录；两个原有音频文件夹「逐句朗读音频」「全文朗读音频」仍与 index.html 同级，无须重传已有音频。本文件夹不含音频。

无需安装或构建，使用 GitHub Pages 发布仓库根目录即可。

中级音频：请另外上传完整的「中级 逐朗读音频」文件夹到仓库根目录，与 index.html 同级；保持文件夹名称中的空格及音频名称。当前已关联 10 个音频文件。

## 逐句录音对照

新增 practice.js，请与 index.html、reading.js 一起上传。点击中文短句后，可听示范、录音、停止、回放、顺序对照及下载。录音仅存当前浏览器 IndexedDB，不上传服务器，每句只保留最新一次，最长 60 秒。浏览器不支持存储时仅保留在当前页面，可下载保存。清除网站数据、更换浏览器或设备后不会保留原录音。

录音需允许麦克风权限，使用 GitHub Pages 的 HTTPS 地址。此版本为人工听音对照，不生成自动评分或发音差异报告。
